# ALASIL POS 1.0 — النسخة النهائية

نظام نقاط بيع كامل (عربي افتراضي / فرنسية).

## التشغيل
```
cd alasil_pos
python3 main.py
```

## الدخول
| الحساب | المستخدم | كلمة السر | الصلاحيات |
|--------|-----------|-----------|-----------|
| مدير | admin | admin | كل الصفحات |
| موظف | employe | emp123 | بيع، جملة، فواتير، عملاء |

التسلسل: شاشة تحميل → تسجيل الدخول → تفعيل (إن لزم، للمدير) → نقطة البيع.

## أهم الوظائف
- نقطة بيع بواجهة صندوق، اختصارات F2–F12، إجمالي أخضر مضيء
- بيع جملة بأسعار ووحدات مستقلة
- منتجات: صلاحية، قفل أسعار، تجزئة/جملة
- فواتير: 5 نماذج + QR يفتح الفاتورة على الهاتف (نفس الشبكة، المنفذ 8765)
- زبائن آجل، إدارة، زكاة، شبكة جهازين، ماسح هاتف
- تخطيط يتكيّف مع حجم الشاشة

## التفعيل
المولّد للبائع فقط: `license_gen.py` أو `dist/ALASIL_License_Gen`  
لا يُوزَّع مع نسخة الزبون. غيّر `SECRET` في `license.py` قبل البيع.

## الهاتف كقارئ / فاتورة QR
الجهاز والهاتف على نفس الواي فاي. الرابط يظهر من زر الماسح في الصندوق.
